# WHAT WOULD YOU DO?

**Every choice changes the story.**

A TUBUO Writes interactive educational game focused on gender-based violence (GBV), rights, safety, evidence, empathy and responsible action.

## Season 1

Season 1 contains five progressive stages with 200 decision challenges:

- Stage 1 — 20 challenges — pass at 70% (14/20)
- Stage 2 — 30 challenges — pass at 70% (21/30)
- Stage 3 — 40 challenges — pass at 70% (28/40)
- Stage 4 — 50 challenges — pass at 70% (35/50)
- Stage 5 — 60 challenges — pass at 70% (42/60)

The game is designed to show one question at a time, give immediate answer feedback and explanation, track progress and skill areas, preserve progress locally, and unlock each stage only after the player reaches the required threshold.

## Safeguarding

This is an educational game, not an emergency service. It does not ask players to disclose personal experiences of violence. Scenarios should never blame survivors, trivialize violence, encourage vigilantism, or assume that the same laws and emergency services apply everywhere.

## TUBUO Writes

WHAT WOULD YOU DO? is a TUBUO Writes original. The game is intended to integrate with the TUBUO Writes website and its public-interest work on GBV, human rights, evidence and advocacy.
